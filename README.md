## ฟังก์ชันที่มีแล้วตอนนี้ (Feature list)

### 2. แผนรายวัน (Itinerary) — ตารางเวลาแก้ไขได้ทั้งหมด
- โครงปัจจุบัน: 20 Narita→นัดข้าวกับญาติ(กลางวัน)→เย็นเข้า Utsunomiya · 21 เดย์ทริป Nikko ไป-กลับ · 22 Utsunomiya ครึ่งวัน→Fukushima · 23 Urabandai ทะเลสาบ (เต็มวัน ①) · 24 เดินเขา (เต็มวัน ②) · 25 ครึ่งวัน → Tokyo บ่าย 3 · 26–28 Tokyo
- แต่ละวันเป็น**ตาราง เวลา / กิจกรรม + รายละเอียด / ราคา** แก้ได้ทุกช่อง พิมพ์แล้วบันทึกทันที (70 แถวในแผนเริ่มต้น)
- เพิ่ม–ลบแถว, เพิ่ม–ลบทั้งวัน, เปลี่ยนพื้นที่ของแต่ละวัน (เปลี่ยนสีการ์ดตาม)
- มุมการ์ดโชว์ยอดรวมราคาของวันนั้น · ปุ่ม「＋งบ」ส่งยอดทั้งวันเข้าเป็นรายจ่ายหมวด「ตั๋วเข้าชม/กิจกรรม」
- แถบล่างสรุปราคารวมของทั้งแผน (เยน + บาท)
- ปุ่ม 📍 ในการ์ดแต่ละวัน → เลื่อนไปแผนที่ + ซูมไปหมุดเฉพาะของวันนั้น
- ปุ่มรีเซ็ตกลับเป็นแผนเริ่มต้น (`DEFAULT_ITINERARY`)
- ถ้าแผนเริ่มต้นในโค้ดถูกอัปเดต (`ITINERARY_VERSION`) เครื่องที่เคยบันทึกแผนไว้จะขึ้นแถบให้เลือกว่าจะโหลดของใหม่ทับ หรือใช้ของเดิมต่อ — ไม่ทับข้อมูลผู้ใช้เอง
- รายการรูปแบบเก่า (สตริงล้วน) ถูกแปลงเป็นแถวตารางอัตโนมัติ ดึงเวลาที่ขึ้นต้นข้อความมาใส่ช่องเวลาให้

### 3. ที่พัก (Airbnb 4 คน 8 คืน)
- แบ่งเป็น 4 ช่วง: Shinjuku 20–21 ต.ค. (1 คืน) · Utsunomiya 21–22 ต.ค. (1 คืน) · Fukushima 22–25 ต.ค. (3 คืน) · Shinjuku 25–28 ต.ค. (3 คืน)
- ย่านแนะนำรอบ Shinjuku 4 ตัวเลือก: Nishi-Shinjuku · Shin-Okubo/Okubo · Yoyogi/Sendagaya · Nakano
- **กล่องเตือนกฎ minpaku ของเขต Shinjuku** — โซนที่อยู่อาศัยเปิดได้เฉพาะเสาร์-อาทิตย์/วันหยุด ซึ่งไม่ตรงกับคืนที่เราพัก
- ตั้งเพดานงบ ฿1,200/คน/คืน (แก้ได้) → คิดเป็น ฿4,800/คืนทั้งหลัง และเช็คให้ทุกช่วงว่าเกินไหม
- ลิงก์ Airbnb ที่ wishlist ไว้แล้วสำหรับ Utsunomiya และ Fukushima
- Tokyo: 4 ย่านที่แนะนำ (Ueno/Okachimachi, Asakusa/Kuramae, Nippori, Shinjuku) พร้อมเหตุผลว่าทำไม และลิงก์ค้นหา Airbnb ที่กรองไว้แล้ว (4 คน · วันที่ตรงช่วง · ห้องน้ำ 1+ · ทั้งหลัง · เพดานราคา)
- กรอกราคา ฿/คืน และลิงก์ห้องที่เลือกได้ → บันทึกอัตโนมัติ + ยอดรวมไหลเข้างบหมวด「ที่พัก」
- สรุปยอด: รวมทั้งทริป, ตกคนละเท่าไหร่, เทียบเพดาน และเทียบงบที่ตั้งไว้
- กล่องสรุปว่าที่พักกับแผนรายวันตรงกันแล้ว (20 ต.ค. เข้า Utsunomiya เย็นหลังนัดข้าวกับญาติที่โตเกียว · 21 เดย์ทริป Nikko ไม่ย้ายที่พัก · 22 ย้ายเข้า Fukushima)
- **กระเป๋าส่งล่วงหน้าแบบ Same-day Delivery จาก Narita** — ยื่นเช้า 09:00-18:00 ถึงที่พักภายใน ~21:00 คืนเดียวกัน ไม่ต้องแบกกระเป๋าใหญ่ไปงานนัดญาติ

### 4. แผนที่ปักหมุด (Leaflet)
- **74 หมุด** ครอบคลุมทุกจุดในแผน + ที่พัก + พิพิธภัณฑ์/งานสถาปัตยกรรมนอกเส้นทาง
- หมุดแยกสีตามพื้นที่ (Tokyo / Tochigi / Nikko / Fukushima / อื่น ๆ ทั่วญี่ปุ่น) — รวม 108 จุด
- ตัวกรองพื้นที่ + ตัวกรองประเภท (🏛 พิพิธภัณฑ์ / ✏️ งาน Yoshio Taniguchi / 🛏 ที่พัก / 🚗 เช่ารถ / 🔭 ที่เที่ยวตัวเลือก)
- หมุดที่พักโชว์วันที่ จำนวนคืน ราคาที่กรอกไว้ (พร้อมเช็คเพดาน) และปุ่มเปิดไปกดจองต่อใน Airbnb
  — หมุดปักที่ **สถานี/ย่าน** ไม่ใช่พิกัดบ้านจริง เพราะ Airbnb ไม่เปิดเผยตำแหน่งจนกว่าจะจอง
- เส้นทางหลักแบบเส้นประ เปิด–ปิดได้
- ลิสต์สถานที่ข้างแผนที่ — คลิกเพื่อบินไปที่หมุดและเปิด popup
- popup มีรูปภาพ (Wikimedia Commons), คำอธิบาย, ราคาบัตร, ลิงก์เว็บทางการ และลิงก์เปิดใน Google Maps
- **🆕 สลับภาษาแผนที่ EN ⇄ ไทย** — ดูรายละเอียดด้านล่าง

### 5. คลังสถานที่ + เงื่อนไขการเดินทาง (`RESEARCH_SPOTS`)
สถานที่ 33 จุดจากการค้นคว้า สำหรับเลือกว่าจะใช้เมืองไหนเป็นฐานช่วง 21–25 ต.ค.
- แบ่งตามฐาน 11 แห่ง: ฟุกุชิมะ · เซนได · มัตสึโมโตะ · นางาโนะ · กุนมะ · อาโอโมริ · กิฟุ · โทยามะ · นีงาตะ · เกียวโตเหนือ · คุมาโมโตะ
- แต่ละใบมี **ไฮไลต์ / วิธีไปทีละต่อพร้อมราคา / ป้ายเงื่อนไข (`SPOT_NEEDS`) / สถานะฤดูปลาย ต.ค. / กล่องคำเตือน**
- ป้ายเงื่อนไข 11 แบบ เช่น 📅 บัสตามฤดูกาล · ⛔ ไม่มีบัสช่วงเรา · 🚗 ต้องมีรถ · 🚫 ห้ามนำรถเข้า · 💴 เงินสดเท่านั้น · 🎫 ต้องจองล่วงหน้า · ❄️ ใกล้ปิดฤดูกาล
- ป้าย fit บอกว่าเข้ากรอบ 21–25 ต.ค. ไหม (เข้ากรอบ / ไปได้แต่ฝืน / นอกกรอบ) · ★ = จุดที่ผู้ใช้ส่งลิสต์มาเอง
- ปุ่ม 📷 **รูปช่วง ต.ค.** ค้นรูปด้วยชื่อญี่ปุ่น + 紅葉 + 10月 (ไม่ฝังรูปตาย เพราะ sandbox เข้า Commons/Flickr/Wikipedia ไม่ได้จึงยืนยัน URL รูปไม่ได้)
- หมุดทั้ง 33 จุดอยู่บนแผนที่ใต้ตัวกรอง 🔭 (รวมหมุดทั้งเว็บ 108 จุด)

### 6. การเดินทาง & ค่าเดินทาง
- **23 ต.ค. เป็นวันขับรถเที่ยวธรรมชาติ Urabandai** — เส้นทางออกแบบให้ไม่เหนื่อย: ทางด่วนแทน Bandai-Azuma Skyline (โค้งเยอะ + ใบไม้บนที่สูงมักพีคไปแล้ว), เดินสั้น ๆ ที่ Nakatsugawa (5 นาที) และ Goshiki-numa แบบไป-กลับ (40-50 นาที) แทนเดินทะลุ 3.6 กม., จบด้วยล่องเรือ Hibara ที่นั่งเฉย ๆ · ยังใส่ตัวเลือก 🔁 ทั้งแบบเดินเต็มเส้นและแบบไม่มีรถไว้เทียบ
- แยกเป็นช่วง ๆ ตามวัน แต่ละช่วงมีหลายตัวเลือก (วิธี / เวลา / ราคา)
- **ตารางค่ารถไฟเมืองต่อเมือง 9 เส้นทาง / 23 ตัวเลือก** (`RAIL_FARES` ใน data.js) — วิธี / เวลา / จำนวนครั้งที่เปลี่ยนขบวน / ราคาต่อคน + ราคา ×4 คน
  - ไฮไลต์แถวถูกที่สุดของแต่ละเส้นทางด้วย 💰 (เช่น Tokyo→Utsunomiya รถธรรมดา ¥2,090 ถูกกว่าชินคันเซ็นเกินครึ่งและไม่ต้องเปลี่ยนขบวน)
  - ป้าย `อ้างอิงแล้ว` = มีแหล่งข้อมูลตรง · `ประมาณการ` = คำนวณจากตารางค่าโดยสาร JR ตามระยะทาง
  - ทุกเส้นทางมีปุ่ม **เช็คราคาสด** เปิด Google Maps transit ระหว่างสองสถานีนั้น
  - `RAIL_LOCAL_NOTES` เก็บค่ารถย่อย (Iizaka Onsen, บัส Urabandai, บัส Chuzenji ฯลฯ)
- ปุ่ม「＋งบ」บันทึกตัวเลือกนั้นเข้าเป็นรายจ่ายจริงในเครื่องคิดงบทันที
- กล่องเปรียบเทียบว่าคุ้มไหมถ้าซื้อ JR EAST PASS (คำนวณจากราคารถไฟจริงในแผน)
- กล่องเปรียบเทียบ **เช่ารถ 2 วันที่ Fukushima vs ขนส่งสาธารณะ** (`CAR_PLAN` ใน data.js) — หาร 4 คนแล้วถูกกว่าราว ¥14,000/คน พร้อมเงื่อนไขใบขับขี่สากลและเวลาปิดประตู Skyline
- วันเดินเขามี 4 ทางไป Jododaira ให้เทียบ: เช่ารถ / Sky Access / บัสไป Takayu + แท็กซี่ / แท็กซี่เหมา
- **ร้านเช่ารถรอบสถานี Fukushima 5 เจ้า** (`CAR_RENTALS` ใน data.js) — ระยะเดินจากสถานี ลิงก์หน้าจอง ปุ่มเปิด Google Maps และปุ่ม 📍 กระโดดไปหมุดบนแผนที่ + เว็บเทียบราคา 5 แห่ง

### 7. เดินเขา Mt. Issaikyo (一切経山)
- ไทม์ไลน์รายชั่วโมงของวันเดินเขา (Plan A) + เส้นทางสำรอง (Plan B) เมื่ออากาศไม่เหมาะ
- เกณฑ์ GO / NO-GO, ลิสต์อุปกรณ์, ตารางค่าใช้จ่าย, ลิงก์เช็คสภาพเส้นทาง/ประกาศภูเขาไฟ

### 6.5 บล็อก Fukushima 4 วัน 3 คืน (22–25 ต.ค.)
จัดเป็น **ครึ่งวัน–เต็มวัน–เต็มวัน–ครึ่งวัน** ตามที่ต้องการ:
| วัน | รูปแบบ | สาระ |
|---|---|---|
| พฤ. 22 | ครึ่งวัน ① | เช้า Utsunomiya (Oya) → ชินคันเซ็น 13:30 → ถึง 14:40 · เย็นเกี๊ยวซ่าจานกลม |
| ศ. 23 | เต็มวัน ① (🚗 ขับรถ ไม่เหนื่อย) | เช่ารถ → ทางด่วนเลี่ยง Skyline → หุบเขา Nakatsugawa (เดิน 5 นาที) → Goshiki-numa ไป-กลับสั้น → เรือทะเลสาบ Hibara |
| ส. 24 | เต็มวัน ② (ธรรมชาติลุย) | เดินเขา Mt. Issaikyo (สลับกับวันศุกร์ได้ถ้าอากาศแย่) |
| อา. 25 | ครึ่งวัน ② | เช้า Hanamiyama + ของฝาก → ชินคันเซ็น 13:20 → ถึง Tokyo 15:00 |

### ข้อมูลเที่ยวฟุกุชิมะช่วงปลายตุลาคม
รวบรวมจากเว็บทางการของจังหวัด/เมือง (fukushima.travel, f-kankou.jp) และ welovefukushima —
เจาะเฉพาะสิ่งที่ทำได้จริงในช่วง 22–25 ต.ค. ที่พักอยู่ Fukushima:
- Azuma Sports Park — อุโมงค์แปะก๊วย 116 ต้น + light-up 17:00–20:00 (เริ่มราว 20 ต.ค.)
- Fruit Line — เก็บแอปเปิล Fuji (ฤดู ต.ค.)
- Iizaka Onsen — โรงอาบน้ำเก่า Sabakoyu (~¥200) + ไข่เรเดียม
- เกี๊ยวซ่าจานกลม 円盤餃子 ของขึ้นชื่อประจำเมือง
- Mt. Shinobu — ภูเขาเตี้ยกลางเมือง เดินได้จากสถานี
- Urabandai — บึงห้าสี Goshiki-numa (เดิน 3.6 กม. ทางราบ), ทะเลสาบ Hibara (เรือชมวิวถึงต้น พ.ย.), หุบเขา Nakatsugawa
- ทะเลสาบ Inawashiro — ตัวเลือกใกล้กว่า ปลาย ต.ค. หงส์อพยพเริ่มมา
- ทางเลือกไปไกลอื่น ๆ: Tsuruga Castle + Ouchi-juku (Aizu), เทศกาลตุ๊กตาเบญจมาศ Nihonmatsu

## 🆕 แผนที่ภาษาอังกฤษ (map in English)

| ชื่อพื้นที่ | `AREA_LABELS_EN` (เช่น "Elsewhere in Japan") |
| ป้ายตัวกรอง / ข้อความ UI ของแผนที่ | `MAP_UI.en` |
| ป้ายชื่อบนตัวแผนที่ | สลับ tile เป็นชุดที่ป้ายเป็นภาษาอังกฤษ (Esri) — โหมดไทยใช้ OpenStreetMap ที่ป้ายเป็นภาษาญี่ปุ่นตามเดิม |
| ลิงก์ค้นหา | ค้นด้วยชื่ออังกฤษ + `hl=en` แทนชื่อไทย+คันจิ |

### เลือกสไตล์แผนที่เองได้

ป้ายชื่อ **บนตัวแผนที่** มาจาก tile server ไม่ใช่โค้ดของเรา — OpenStreetMap ใช้ชื่อท้องถิ่น (ญี่ปุ่น) เสมอ
ไม่ว่าจะตั้งภาษาอะไร จึงมีปุ่มเลือก basemap แยกไว้ในแถวตัวกรองประเภท:

| ปุ่ม | ใช้ tile | ป้ายชื่อ |
|---|---|---|
| `EN · Street` (ค่าเริ่มต้น) | Esri World Street Map | อังกฤษ |
| `EN · Light` | Esri Light Gray Base + Reference | อังกฤษ พื้นอ่อน อ่านง่ายกว่าเวลาหมุดเยอะ (ซูมสุดที่ 16) |
| `日本語 · OSM` | OpenStreetMap | ญี่ปุ่น |

ตัวเลือกนี้จำไว้ในเครื่องแยกจากภาษาของข้อมูล — เลือก OSM ไว้ขณะที่ข้อมูลยังเป็นอังกฤษก็ได้

ทุกหมุดยังแสดงชื่อภาษาญี่ปุ่น (漢字) ควบคู่เสมอ — เอาไว้ชี้ให้คนญี่ปุ่นดูหรือพิมพ์ค้นในแอปญี่ปุ่นได้ทั้งสองโหมด

### เพิ่มหมุดใหม่ให้รองรับสองภาษา

ใส่ `en` เข้าไปในอ็อบเจกต์ของสถานที่ใน `js/data.js`:

```js
{ name: 'ชื่อไทย', ja: '日本語', area: 'tokyo', lat: 35.0, lng: 139.0, day: 7,
  desc: 'คำอธิบายภาษาไทย',
  en: { name: 'English name', desc: 'English description', ticket: 'English ticket info' } },
```

ถ้าไม่ใส่ `en` ระบบจะ fallback กลับไปใช้ข้อมูลภาษาไทยโดยไม่พัง

## รูปแบบข้อมูลแผนรายวัน

```js
{ day: 1, date: 'อ. 20 ต.ค.', area: 'tokyo', title: 'หัวข้อของวัน', items: [
  { t: '09:30', act: 'กิจกรรม', note: 'รายละเอียด/หมายเหตุ', cost: 3070 },  // cost = เยน ต่อคน
]}
```

แก้แผนเริ่มต้นแล้วอย่าลืมบวก `ITINERARY_VERSION` ขึ้น 1 เพื่อให้เครื่องที่เคยเปิดเว็บรู้ว่ามีของใหม่

## แก้ข้อมูลที่พัก

ทุกอย่างอยู่ในตัวแปร `STAYS` (`js/data.js`) — เปลี่ยนวันที่ จำนวนคืน สถานี หรือย่านที่แนะนำได้ที่นั่น
หมุดบนแผนที่สร้างจาก `STAYS` อัตโนมัติ (ลูป `STAYS.forEach` ใต้ตัวแปร) ไม่ต้องเพิ่มหมุดเองซ้ำ

- `STAY_CAP_PER_PERSON_THB` — เพดานเริ่มต้นต่อคน/คืน (฿1,200)
- `STAY_GUESTS` — จำนวนคน (4)
- `airbnbSearch()` — ตัวสร้างลิงก์ค้นหา Airbnb ที่ใส่ฟิลเตอร์ให้แล้ว
- ราคาและลิงก์ที่กรอกในหน้าเว็บเก็บที่ `localStorage.jt26_stays` (ไม่ได้ hardcode ไว้ในโค้ด)
