# 秋の旅 — Japan Autumn Trip 2026

เว็บวางแผนทริปญี่ปุ่น **20–28 ตุลาคม 2026** (Tokyo → Tochigi → Nikko → Fukushima → Tokyo)
Static site ล้วน ๆ — เปิด `index.html` ได้เลย ไม่ต้อง build ไม่ต้องมี server

---

## ฟังก์ชันที่มีแล้วตอนนี้ (Feature list)

### 1. Hero + นับถอยหลัง
- นับถอยหลังจำนวนวันก่อนออกเดินทางอัตโนมัติ (`TRIP.start` / `TRIP.end`)
- ระหว่างทริปเปลี่ยนเป็น 🎌 และหลังจบทริปเปลี่ยนเป็น ✈ พร้อมข้อความของตัวเอง
- แถบเส้นทาง (route strip) แยกสีตามพื้นที่

### 2. แผนรายวัน (Itinerary) — แก้ไขได้ทั้งหมด
- แก้ วันที่ / หัวข้อ / รายการย่อย ได้ทุกช่อง พิมพ์แล้วบันทึกทันที
- เพิ่ม–ลบรายการย่อย, เพิ่ม–ลบทั้งวัน, เปลี่ยนพื้นที่ของแต่ละวัน (เปลี่ยนสีการ์ดตาม)
- ปุ่ม 📍 ในการ์ดแต่ละวัน → เลื่อนไปแผนที่ + ซูมไปหมุดเฉพาะของวันนั้น
- ปุ่มรีเซ็ตกลับเป็นแผนเริ่มต้น (`DEFAULT_ITINERARY`)

### 3. แผนที่ปักหมุด (Leaflet)
- **51 หมุด** ครอบคลุมทุกจุดในแผน + พิพิธภัณฑ์/งานสถาปัตยกรรมนอกเส้นทาง
- หมุดแยกสีตามพื้นที่ (Tokyo / Tochigi / Nikko / Fukushima / อื่น ๆ ทั่วญี่ปุ่น)
- ตัวกรองพื้นที่ + ตัวกรองประเภท (🏛 พิพิธภัณฑ์ / ✏️ งาน Yoshio Taniguchi)
- เส้นทางหลักแบบเส้นประ เปิด–ปิดได้
- ลิสต์สถานที่ข้างแผนที่ — คลิกเพื่อบินไปที่หมุดและเปิด popup
- popup มีรูปภาพ (Wikimedia Commons), คำอธิบาย, ราคาบัตร, ลิงก์เว็บทางการ และลิงก์เปิดใน Google Maps
- **🆕 สลับภาษาแผนที่ EN ⇄ ไทย** — ดูรายละเอียดด้านล่าง

### 4. การเดินทาง & ค่าเดินทาง
- แยกเป็นช่วง ๆ ตามวัน แต่ละช่วงมีหลายตัวเลือก (วิธี / เวลา / ราคา)
- ปุ่ม「＋งบ」บันทึกตัวเลือกนั้นเข้าเป็นรายจ่ายจริงในเครื่องคิดงบทันที
- กล่องเปรียบเทียบว่าคุ้มไหมถ้าซื้อ JR EAST PASS (คำนวณจากราคารถไฟจริงในแผน)

### 5. เดินเขา Mt. Issaikyo (一切経山)
- ไทม์ไลน์รายชั่วโมงของวันเดินเขา (Plan A) + เส้นทางสำรอง (Plan B) เมื่ออากาศไม่เหมาะ
- เกณฑ์ GO / NO-GO, ลิสต์อุปกรณ์, ตารางค่าใช้จ่าย, ลิงก์เช็คสภาพเส้นทาง/ประกาศภูเขาไฟ

### 6. Events เดือนตุลาคม
- การ์ด event พร้อมสถานะ: ทันทริป ✓ / พลาด / รอประกาศ
- กรองตามพื้นที่ หรือกรองเฉพาะงานที่ทันทริป
- รวมนิทรรศการพิเศษของพิพิธภัณฑ์ที่ปักหมุดไว้ (เช็ควันจริงปี 2026 แล้ว)
- ลิงก์แหล่งข้อมูลไว้เช็ค event สดใกล้วันเดินทาง

### 7. ลิสต์ของที่จะซื้อ
- เพิ่ม–ลบของ, ติ๊กเมื่อซื้อแล้ว, แยกหมวด, คิดราคารวม × จำนวน
- ยอด "ซื้อแล้ว" ไหลเข้าไปรวมในงบหมวด「ช้อปปิ้ง」อัตโนมัติ
- สรุปยอดเป็นเงินเยนและเงินบาท

### 8. งบประมาณ & รายจ่าย
- ตั้งงบรายหมวดได้เอง พร้อมแถบ progress และเตือนเมื่อเกินงบ
- บันทึกรายจ่ายจริงแยกตามหมวด/วัน ลบได้
- ตั้งอัตราแลกเปลี่ยน JPY→THB เอง แล้วแปลงยอดทั้งหมดให้อัตโนมัติ

### 9. บันทึกข้อมูล & ซิงค์
- ทุกอย่าง (แผนรายวัน, ของที่จะซื้อ, งบ, รายจ่าย, เรตเงิน, ภาษาแผนที่) เก็บใน `localStorage`
- ซิงค์ข้ามอุปกรณ์ผ่าน Firestore ถ้าตั้งค่าไว้ (`js/firebase-config.js`) พร้อมตัวบอกสถานะซิงค์บน nav

## 🆕 แผนที่ภาษาอังกฤษ (map in English)

ปุ่ม **EN / ไทย** อยู่ท้ายแถวตัวกรองพื้นที่ ค่าเริ่มต้นคือ **EN** และจำค่าที่เลือกไว้ในเครื่อง

เมื่อเลือก EN จะเปลี่ยนทั้งหมดนี้:

| ส่วน | ผลลัพธ์ |
|---|---|
| ชื่อสถานที่ | ใช้ชื่ออังกฤษ (`en.name`) เช่น "Sensoji Temple (Asakusa)" |
| คำอธิบาย | คำอธิบายภาษาอังกฤษ (`en.desc`) ครบทั้ง 51 หมุด |
| ข้อมูลบัตร | `en.ticket` ของทุกหมุดที่มีราคา |
| ชื่อพื้นที่ | `AREA_LABELS_EN` (เช่น "Elsewhere in Japan") |
| ป้ายตัวกรอง / ข้อความ UI ของแผนที่ | `MAP_UI.en` |
| ป้ายชื่อบนตัวแผนที่ | สลับ tile เป็นชุดที่มีป้ายภาษาอังกฤษ (Esri World Street Map) — โหมดไทยใช้ OpenStreetMap ที่ป้ายเป็นภาษาญี่ปุ่นตามเดิม |
| ลิงก์ค้นหา | ค้นด้วยชื่ออังกฤษ + `hl=en` แทนชื่อไทย+คันจิ |

ทุกหมุดยังแสดงชื่อภาษาญี่ปุ่น (漢字) ควบคู่เสมอ — เอาไว้ชี้ให้คนญี่ปุ่นดูหรือพิมพ์ค้นในแอปญี่ปุ่นได้ทั้งสองโหมด

### เพิ่มหมุดใหม่ให้รองรับสองภาษา

ใส่ `en` เข้าไปในอ็อบเจกต์ของสถานที่ใน `js/data.js`:

```js
{ name: 'ชื่อไทย', ja: '日本語', area: 'tokyo', lat: 35.0, lng: 139.0, day: 7,
  desc: 'คำอธิบายภาษาไทย',
  en: { name: 'English name', desc: 'English description', ticket: 'English ticket info' } },
```

ถ้าไม่ใส่ `en` ระบบจะ fallback กลับไปใช้ข้อมูลภาษาไทยโดยไม่พัง

## โครงสร้างไฟล์

```
index.html              โครงหน้าเว็บทั้งหมด
css/style.css           ธีม washi/ญี่ปุ่น + responsive
js/data.js              ข้อมูลทริปทั้งหมด (หมุด, itinerary, transport, events, งบ, สตริง 2 ภาษา)
js/app.js               ลอจิกทั้งหมด (แผนที่, ตัวกรอง, i18n, งบ, ช้อปปิ้ง, localStorage)
js/sync.js              ซิงค์ผ่าน Firestore
js/firebase-config.js   ค่าคอนฟิก Firebase
```

Dependencies โหลดจาก CDN: Leaflet 1.9.4, Firebase 10.14.1 (compat), Google Fonts
